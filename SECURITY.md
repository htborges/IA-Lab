# Security Policy

> 🇺🇸 English · 🇧🇷 Português abaixo

The labs in this repository are **intentionally vulnerable**. Run them only locally or in isolated environments, never exposed to the internet.

If you find a problem that is **not** an intended vulnerability (for example, a lab that exposes the host, or a leaked secret), please open a [private security advisory](../../security/advisories/new) instead of a public issue.

---

## 🇧🇷 Política de Segurança

Os labs deste repositório são **intencionalmente vulneráveis**. Rode-os apenas localmente ou em ambientes isolados, nunca expostos à internet.

Se encontrar um problema que **não** seja uma vulnerabilidade proposital (por exemplo, um lab que expõe o host ou um segredo vazado), abra um [security advisory privado](../../security/advisories/new) em vez de uma issue pública.
